# 1. Introduction

Home Assistant is an open-source home-automation platform that households run on their own hardware. It controls a home's physical devices, door locks and alarm panels included, and its optional analytics counted 669,743 active installations in August 2026 (Home Assistant, n.d.-d).

The platform reaches each device or online service through an integration, a module written for that device or service. Many are written by the community rather than the platform's maintainers, and 56.6% of reporting installations run the Home Assistant Community Store that distributes them (Home Assistant, n.d.-d). An integration is not a separate program that the platform supervises. Home Assistant loads it into its own running process, where it shares the platform's privileges and network access and can read and change the state of the whole system (Home Assistant, n.d.-g). Nothing separates the integration from the platform, and nothing records what access it needs, so an integration that reports pollen counts and one that operates a door lock can reach exactly the same things.

This design is reasonable for code that the platform's maintainers review. The difficulty is that the same mechanism carries code that no one is obliged to review, delivered through an update channel that owners already trust. Twenty-seven community integrations each run in more than 10,000 reporting installations, so one hostile release of any of them would reach thousands of homes with the platform's full authority, locks and alarms included.

This project builds and evaluates a framework that confines each community integration without changing its code or the platform's. Each integration runs in its own sandbox, and every effect it has on the household's installation passes through a separate process, the mediator. The mediator allows only what the integration's permissions declare, after a person has read and approved them in Home Assistant's own interface, and it records every decision it takes. The evaluation runs integrations with and without confinement on a Raspberry Pi 5: hostile integrations written for the purpose test whether the confinement holds, and 75 real community integrations test whether they still work and what confinement costs. Together they test whether an integration's authority can become something a household sees and limits, rather than something it inherits by installing.
