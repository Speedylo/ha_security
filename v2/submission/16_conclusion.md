# 16. Conclusion

Home Assistant runs community integrations inside its own process, with the platform's full authority, so an integration installed to show electricity prices can also read the household's stored passwords and see when the house is empty. This project built a framework that confines each integration in a sandbox of its own, where what it may do is declared before it is installed, enforced while it runs and recorded each time it is used. The integrations and the platform run unchanged.

The evaluation answered its three questions on a Raspberry Pi 5. Confinement protects the household: the published attacks that motivated the project, reaching another integration's credential through the garbage collector and stealing files through the 2021 path-traversal pattern, succeeded without the framework and found nothing with it. Integrations still work: across 75 real community integrations in two samples, confinement caused none of the failures to load, fifteen named integrations worked end to end, and the bridge now covers the device kinds of 36 of the 37 most-installed integrations. A home device can afford it: the device holds at least 17 sandboxes, about four times what the average installation needs, and mediation adds delays too small for a household to notice.

These answers have limits. Every attack was written within the project, and no independent tester has yet attacked the framework. Every manifest in the evaluation was written by the project, so how manifests would be supplied for the whole ecosystem is still open. The results describe one release of Home Assistant on one device, and three camera integrations lose their live video when confined.

Within those limits, the project changes what an integration's authority is. Authority that was total and invisible becomes declared, bounded and recorded, so a household can know what each integration may do and what it has done. A lasting fix would require Home Assistant to place community integrations behind a process boundary itself, because a check inside its own process can be reached by the code it restricts (Corno & Mannella, 2022). This project provides the evidence such a change would need: what confinement costs, what a declaration must express and which threats it closes.
