# 2 Problem Statement

A community integration in Home Assistant runs inside the platform itself and receives the platform's full authority. It can read the state of every device in the home, which reveals when the household is present or away, and it can call any action the platform offers, including unlocking a door or disarming an alarm (Home Assistant, n.d.-a, n.d.-d). It can also read the credentials the platform stores for the household's online accounts (Home Assistant, 2021). It can even add its own web pages to the platform's web server and switch off their login check, handling authentication itself. Such home-made checks are a known source of flaws: elttam (2023) found one in an integration shipped with the platform that let a remote attacker, without any password, run code on the installation and take full control of the home's devices and stored credentials. Even integrations are not protected from each other: Corno and Mannella (2022) showed that one integration can reach into another's memory and read or change its private data, so a safeguard placed inside the platform could itself be bypassed.

None of the existing safeguards limits what an integration does once it is installed. The community store checks that an integration's repository is correctly structured, not what its code does (HACS, n.d.). Community review of the public source code helps, but it is weakest for the many small integrations with few users, it covers only the version that was read, and it can miss well-hidden malicious code, as the XZ Utils backdoor showed when a contributor spent more than two years earning trust before inserting one (Przymus & Durieux, 2025). In 2021, flaws in the community store and seven other integrations allowed an attacker to read any file the platform could read, including stored credentials (Home Assistant, 2021).

The platform's position is that users install community integrations at their own risk (Home Assistant, 2021), and such attacks are excluded from its security programme (Home Assistant, n.d.-c). The owner therefore carries a risk they have no means to manage: they cannot see what an integration will access before installing it, limit it while it runs, or find out afterwards what it did.

There is therefore a need for a mechanism through which an integration's permissions are declared, approved by the owner, enforced while it runs and recorded, without changing the integrations or the platform.
